# Bug 报告

- **发现者**: QA
- **发现时间**: 2026-05-13 11:35
- **严重度**: **critical** — 整个应用不可用
- **相关文件**: `SAHG.Salt.EntityFramework/EntityFramework/SaltDbContext.cs:1407`

## 描述

IIS 应用池 `8088_fenluapi` 重启后，所有 API 请求（包括 Login）均返回 `InvalidOperationException`：

> The model backing the 'SaltDbContext' context has changed since the database was created. Consider using Code First Migrations to update the database.

新增的 CodeGenerator 实体（CodeRecordObject 或类似实体）改变了 EF Code First 模型，但数据库未执行相应的 Migration。

## 复现步骤

1. 重启 IIS 应用池 `8088_fenluapi`
2. 访问任意 API 接口（包括 `POST /api/Common/Account/Login`）
3. 返回 500 错误，`SaltDbContext` 初始化失败

## 期望 vs 实际

| 期望 | 实际 |
|------|------|
| API 正常响应，Login 返回 Token | 整个应用崩溃，所有接口返回 EF 模型变更错误 |

## 根因分析

EF 使用 `CreateDatabaseIfNotExists` 初始化策略。新增实体后模型与现有数据库 schema 不匹配，EF 检测到模型变更后拒绝初始化。

## 建议修复

1. 执行 EF Code First Migration 更新数据库（`Add-Migration` + `Update-Database`）
2. 或手动在数据库中添加缺失的表（如 `CodeRecordObjects` 等新表）
3. 修复后重启 IIS 应用池并验证 Login 可用
