# Bug 报告

- **发现者**: QA
- **发现时间**: 2026-05-13 14:36
- **严重度**: **high** — 核心接口不可用，无 workaround
- **相关文件**: `SAHG.Salt.WebAppApi/Areas/Produce/Controllers/ProduceWorkOrderController.cs`（推测）

## 描述

`POST /api/Produce/ProduceWorkOrder/GetPageListForCodeGen` 持续返回 NullReferenceException，无论传入什么参数。

## 复现步骤

1. 登录获取 Token
2. 调用 `POST /api/Produce/ProduceWorkOrder/GetPageListForCodeGen`
3. 入参: `{"SkipCount":0,"MaxResultCount":10}`
4. 返回: `{"success":false,"error":{"code":-1,"message":"未将对象引用设置到对象的实例。"}}`

## 期望 vs 实际

| 期望 | 实际 |
|------|------|
| 返回工单列表，含 `generatedCodeCount` 字段 | `success:false, error: NullReferenceException` |

## 影响

- 前端 Tab1「未生成编码」和 Tab2「已生成编码」无法加载数据
- 用户无法查看工单编码状态，无法触发编码生成流程

## 补充信息

- 多次重试（不同参数：空参数、带 WorkOrderNo、带 ProductName）均为同一错误
- 现有 `GetPageList` 接口也受 EF 变更影响（之前测试），但修复后未重新验证
- Login API 正常，GenerateCode API 正常，GetCodeRecordsByObject API 正常
