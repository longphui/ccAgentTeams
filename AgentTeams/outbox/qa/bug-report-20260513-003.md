# Bug 报告

- **发现者**: QA
- **发现时间**: 2026-05-13 15:13
- **严重度**: **medium** — 主要功能异常，有 workaround（英文搜索可用）
- **相关文件**: `SAHG.Salt.Application/Produce/ProduceWorkOrderService.cs:868/870`

## 描述

`GetPageListForCodeGen` 中 ProductName/WorkOrderNo 中文搜索导致异常（空错误消息）。英文和数字搜索正常。

## 复现步骤

1. 登录获取 Token
2. 调用 `POST /api/Produce/ProduceWorkOrder/GetPageListForCodeGen`
3. 入参: `{"Data":{"PageNumber":1,"PageSize":5,"ProductName":"测试"}}`
4. 返回: `{"success":false,"error":{"code":-1,"message":""}}`

## 期望 vs 实际

| 期望 | 实际 |
|------|------|
| 返回空列表或匹配项 | success:false, error.message="" |

## 影响

- 用户无法用中文搜索产品名称（系统主要语言为中文）
- WorkOrderNo 中文搜索同样受影响

## 代码位置

`ProduceWorkOrderService.cs:868`: `a.ProductName.Contains(input.ProductName)`
`ProduceWorkOrderService.cs:870`: `a.WorkOrderNo == input.WorkOrderNo`

EF6 将 LINQ 翻译为 SQL 时对中文字符处理异常。
