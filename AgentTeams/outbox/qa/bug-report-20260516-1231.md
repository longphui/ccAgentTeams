# Bug 报告
- **发现者**: QA
- **发现时间**: 2026-05-16 12:31
- **严重度**: high
- **相关文件**: 
  - SAHG.Salt.Application/CodeGenerator/CodeGeneratorService.cs (SaveBizField, SaveBizCode, SaveRule)
  - SAHG.Salt.WebAppApi/Areas/CodeGenerator/Controllers/CodeGeneratorController.cs

## 描述
SaveBizField、SaveBizCode、SaveRule 三个 API 在传入完整参数后，均返回 `{"success":false,"error":{"code":-1,"message":""}}`（空异常消息）。GenerateCode（同样使用 SaltRequest 包装）正常工作，排除 SaltRequest 反序列化问题。

## 复现步骤
1. 登录获取 Token：POST /api/Common/Account/Login
2. 调用 SaveBizField：
```
POST /api/CodeGenerator/CodeGenerator/SaveBizField
{"data":{"fieldName":"test","domainCode":"Product","domainName":"商品","fieldSql":"SELECT 1","description":"test"}}
```
3. 观察返回：`{"success":false,"error":{"code":-1,"message":""}}`

## 期望 vs 实际
| 期望 | 实际 |
|------|------|
| `{"success":true,"result":{"states":true,"tips":"保存成功"}}` | `{"success":false,"error":{"code":-1,"message":""}}` |

## 分析
- 缺少必填字段时能正确返回验证错误（如"业务领域标识不能为空"），说明 CheckData 验证正常
- 问题发生在 CheckData 通过后、EntityFramework Insert/Update 阶段
- GenerateCode（不走 CreateNew/Update）正常，Save 类（走 CreateNew/Update）全部异常
- 可能原因：IIS DLL 未更新、AutoMapper 配置、或 EF 上下文异常
