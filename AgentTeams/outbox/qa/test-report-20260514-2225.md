## 建议
- 中文搜索异常原因：EF6 LINQ to Entities 对 NVARCHAR `Contains()` 的 SQL 翻译可能未正确处理 Unicode
- 建议考虑使用原生 SQL `LIKE N'%keyword%'` 替代 LINQ `Contains`
- 异常 message 为空，建议增加 try-catch 并返回有意义的错误提示
