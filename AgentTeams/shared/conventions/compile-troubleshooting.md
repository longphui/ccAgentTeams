# 编译排错规范

## 缺失文件错误 → 先 svn update

编译时遇到以下类型错误，且涉及文件**不在当前 TASK 范围内**：

- `CS0246` 找不到类型或命名空间
- `FileNotFoundException` / `Could not find file`
- `CS0234` 命名空间中不存在类型
- 缺少引用、程序集不匹配

**处理步骤：**

1. **先 `svn update`** — 拉取其他用户提交的代码。缺失文件大概率是别人提交的依赖，本地工作副本未同步
2. update 后重新编译
3. 仍然报错 → 发 QUERY 给 Architect，附带完整编译日志

**禁止行为：**
- ❌ 模拟添加空类 / 占位文件来绕过编译错误
- ❌ 注释掉不相关代码来让编译通过
- ❌ 手动创建缺失的 DLL / 引用

这些文件不在你的分支/TASK中，强行绕过会在合并时引入真实 Bug。
