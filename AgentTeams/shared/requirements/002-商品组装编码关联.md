# 需求 #002：商品组装编码关联

- **日期**: 2026-05-13
- **提出方**: Architect（与用户沟通确认）
- **状态**: 待分派

---

## 一、需求概述

分路系统中，半成品通过 #001 的工单生成唯一实物编码后，需要将半成品编码与成品进行组装关联。前提：一物一码，成品和半成品都有实物编码。

属于「系统公共工序」（commonProductionStages）的一种。

---

## 二、核心流程

### 2.1 手动组装

```
create_edit.html:
  选成品 → 选成品编码 → 添加组件行（选半成品 + 定数量 + 逐个选编码）
  → 可加多个组件行 → 保存 → 一并写入 ProductComponents + ProductComponentCodes
```

### 2.2 一键自动组合

```
autoAssembly.html（独立页面）:
  只选商品（成品 + 组件半成品）和组件数量，不指定具体编码
  → 系统从未使用编码池中随机组合
  → 每组编码对应的商品数量和指定一致
  → 批量保存
```

### 2.3 编码唯一性

一个编码只能使用一次。保存时查 ProductComponentCodes 表判断编码是否已被绑定。

## 三、前端设计

### 3.1 页面路径

```
views/productionManage/commonProductionStages/ProductComponents/
├── index.html           # 列表页（按成品分组，展开看组件详情）
├── create_edit.html     # 手动组装（复杂，多弹框）
└── autoAssembly.html    # 一键自动组合
```

### 3.2 列表页（index.html）

**分组展示**：按成品信息分组，可点击展开查看每个组件行（半成品名称、数量、编码列表）

**列**：成品名称、成品编码、组件数、创建时间、操作（编辑/删除）

**展开区**：LayuiVue Table expand，展示组件明细

### 3.3 手动组装（create_edit.html）

```
[成品选择区]
  成品: [下拉选择]  成品编码: [下拉/输入选择]

[组件列表区]
  + 添加组件
  组件1: 半成品 [下拉] | 数量 [输入] | 编码 [逐个选择] | 删除
  组件2: 半成品 [下拉] | 数量 [输入] | 编码 [逐个选择] | 删除
  ...

[保存] [取消]
```

**编码选择**：从该半成品已生成且未被使用的编码池中选择，支持下拉/输入

### 3.4 一键自动组合（autoAssembly.html）

```
[选择区]
  成品: [下拉选择]
  组件1: 半成品 [下拉] | 数量 [输入]
  组件2: 半成品 [下拉] | 数量 [输入]
  + 添加更多组件

[自动组合] → 系统随机匹配编码 → 展示组合结果 → [确认保存]
```

## 四、后端设计

### 4.1 实体

**ProductComponents**（继承 `BasicEntity`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| ProductId | int | 成品ID |
| ProductCode | string | 成品编码（可选） |
| ComponentProductId | int | 组件半成品ID |
| ComponentQuantity | int | 半成品数量 |
| ComponentUnit | string | 半成品单位 |
| Codes | ICollection\<ProductComponentCodes\> | 组件编码集合 |

**ProductComponentCodes**（继承 `SaltEntity`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| ProductComponentId | int | 关联 ProductComponents |
| CodeValue | string | 半成品编码值 |

### 4.2 API

| 接口 | 方法 | 模块 | 说明 |
|------|------|------|------|
| `GetPageList` | POST | Produce | 组装列表，按成品分组 |
| `GetDetails` | GET | Produce | 单条详情 |
| `Save` | POST | Produce | 新增/修改手动组装 |
| `AutoAssemble` | POST | Produce | 一键自动组合 + 批量保存 |
| `Delete` | POST | Produce | 删除组装记录 |
| `GetAvailableCodes` | GET | Produce | 获取半成品未使用的编码列表 |

**Controller**：`Produce/ProductComponentsController`，使用 `[PPMLog]`

## 六、关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 实体继承 | ProductComponents 继承 BasicEntity | 需要在 Core/Produce 目录下统一管理 |
| 数据分组 | 按成品信息分组展示 | 用户按成品视角管理组装关系 |
| Controller 日志 | `[PPMLog]` | 组装属于生产管理模块 |
| 一键组合算法 | 随机从未使用编码池取 | 满足需求，实现简单 |
| 编码唯一性 | 保存前查 ProductComponentCodes | 防止一码多用 |
